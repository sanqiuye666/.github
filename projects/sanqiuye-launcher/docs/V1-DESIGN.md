# V1-DESIGN

更新协议按签名元数据、固定文件清单、内容摘要和事务步骤处理。下载完成不代表已安装，安装完成不代表游戏已验证可运行。更新器先核验路径边界、长度与摘要，保留原文件的可恢复副本，再执行事务提交；中断后的恢复使用持久事务记录而非猜测目录状态。管理员发布与玩家应用分离，维护策略与Bootstrap启动许可继续有效。该公共架构摘要也作为打包冒烟测试的非敏感文本输入，不包含任何真实整合包配置或运营资料。各接口的真实与mock实现由统一工厂选择，默认配置不能暗中降级成模拟成功。Minecraft游戏身份、面板账号与管理认证是不同边界；公开账号响应只含允许资料，密码派生值和会话摘要不能进入界面。网络调用必须有界超时、有限重试与分类错误，重试不得改变有副作用操作的语义。备份和回滚按实际所属数据范围执行，不能覆盖玩家自有内容。第三方许可证与上游作者信息随源码和发行包保留。

配置模板和构建步骤见项目README，第三方许可见third-party目录。
