# 三秋叶本机 Demo

双击 `启动Demo.cmd` 打开；或访问启动脚本输出的本机地址。进入后选择“进入本机模式”。本包使用本机 Java 21，未内置 Java 运行时，也不是最终原生 EXE 安装包。

可体验四种布局、最多四套自定义排列、女仆与指引；官方 Java 版目录、隔离实例、原版文件安装、Java 检测、临时离线身份、启动检查和原版启动；Modrinth 搜索与文件库。实际下载需要联网；游戏需匹配的 Java。模组下载入库不等于已安装加载器并激活。

推荐顺序：账号页添加临时离线身份 → 设置检测 Java → 版本中心创建实例 → 实例页安装文件 → 设置选择该实例的 Java → 实例页“启动与日志”检查并启动。此机器已有 Java 21，可先尝试 1.20.6 或 1.21.1；其他版本可能要求其他 Java。

所有实例与运行数据在本文件夹的 `demo-data` 中。关闭网页不会停止后端；先正常退出游戏、完成或取消任务，再双击 `关闭Demo.cmd`。脚本仅关闭本包记录且归属匹配的进程。

布局保存在当前浏览器的本机站点存储中，使用固定端口 15173；不要同时运行两份 Demo。临时离线身份在后端退出后消失，未接入微软/第三方持久认证、云端账号和服务器同步。

梦鱼外置组件拆分尚未实现；原更新器入口目前仍是演示预览。该 Demo 用于体验当前主体，最新四布局仍待整批最终验收，不代表正式发行完成。上游许可与署名随包保留。
